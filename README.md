# Spring Boot Learning Projects & Concepts

This repository serves as a centralized collection of my learning progress, concept demonstrations, and mini-projects built using Java and Spring Boot.

## 📂 Repository Contents

This workspace includes various modules focusing on different Spring framework concepts and practical applications:

### 🛠️ Core Concepts
* **ConceptCircularDependency:** Demonstrates how Spring handles circular dependencies between beans.
* **ConceptSpringLifeCycle:** Examples of bean lifecycle management, initialization, and destruction callbacks.
* **ConceptXMLConfiguration:** Legacy XML-based configuration examples in Spring.
* **CRUDSpringDemo:** Basic Create, Read, Update, and Delete operations using Spring Data JPA.

### 💻 Mini-Projects & Systems
* **StudentInformationSystem:** A module for managing student records and details.
* **CampusManagement:** A system designed to handle campus-related administrative tasks.
* **EventManagementSystem:** A backend application for organizing and managing events.
* **FoodOrderingSystem:** A demonstration of order processing and inventory management.

## 🚀 Tech Stack
* **Language:** Java
* **Framework:** Spring Boot, Spring Core, Spring Data JPA
* **Tools/IDE:** IntelliJ IDEA, Maven, Git
